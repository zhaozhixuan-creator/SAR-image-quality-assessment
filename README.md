# SAR 图像质检实现方案

> 合成孔径雷达（SAR）图像质量检查与评价的完整实现方案：7 维 38 项质检指标体系、分级质检流水线、判据与缺陷分级机制、开源生态选型与分阶段落地路径。

本方案综合两份调研成果：**SAR 图像质检调研**（领域指标体系、分级流水线、判据与开源实现、标准规范）与**训练前数据处理与质检**（五轴质检、五层工程架构、消融闭环）。前者提供"测什么、怎么判"，后者提供"怎么组织、怎么演进"。

---

## 一、方案定位与三条总原则

SAR 质检不能沿用光学影像或自然图像的质量评价范式——主动微波、侧视斜距、相干成像三条性质各自派生出一整类其他成像体制不存在的质量问题，同时又消灭了"参考图像"这个前提。

因此 SAR 质检的难点不在指标难算，而在**判据能否成立**：没有参考图像、物理指标与场景性质纠缠、同一数值在不同测量条件下不可比。整套方案必须同时满足三条原则：

1. **指标在其原生产品级别测量**——L0 测完整性、L1/SLC 测物理性能、L2 测几何、L3+ 测 ARD 合规；跨级测得的数值不可与规格比对。
2. **每个数值附带完整测量条件与改正项**——遵循 CEOS-ARD 的"可追溯性优先于绝对精度"思路；仅"相干性须报告估计窗口"一条，就解决了"数值不可比"问题。
3. **连续物理量通过"超差比例"映射到离散缺陷等级**——接入国内 GB/T 24356-2023「两级检查一级验收」的可审计、可法定化流程。

## 二、总体架构

把五层工程架构落到 SAR 领域，叠加分级质检流水线：

### 分级质检流水线

| 层 | 职责 | 核心质检内容 |
|---|---|---|
| L0 原始级 | 下行完整性、丢包、BAQ 配置、内定标信号 | 丢行/坏像元率、下行链路校验 |
| L1 单视复（SLC）级 | **物理性能指标的唯一正确测量位置** | IRF 分辨率 / PSLR / ISLR / SSLR、NESZ、AASR / RASR、RFI、扇贝 |
| L2 地距 / 地理编码级 | 几何与地形相关 | ALE、RTC 正确性、叠掩阴影掩膜、投影一致性 |
| L3+ 分析就绪级 | ARD 合规与相位质量 | CARD4L 合规、时序辐射一致性、相干性 / 解缠质量 |
| 统一判定层 | 缺陷分级、扣分、批抽样判定 | 超差比例 → A/B/C/D，GB/T 24356 |

### 五层工程实现

- **算子库**：每个指标一个独立算子，输入数据 + 测量条件 → 输出数值 + 元数据（窗口、过采样倍数、加权条件、改正项）。以 sct 的字段命名与默认参数表为对齐基准。
- **编排层**：按产品级别触发算子；场景相关检查（前置筛查）先跑，高成本点目标检查后跑。
- **落库与看板**：结果入库，支持按任务 / 批次 / 处理器版本的分组留存率审计。
- **人工抽检**：按 GB/T 24356 抽样量表执行目视复核，自动指标无法发现的未建模缺陷靠这一层兜底。
- **消融闭环**：任何新过滤 / 新阈值必须跑下游消融才能生效（见第七节）。

## 三、质检指标体系（7 维 38 项）

38 项指标分 7 个维度，维度划分依据是**判据来源相同**（同一维度共享测量对象与验证手段）。

### 维度 1 · 辐射质量（6 项）

| 指标 | 测量方法 | 判据 / 基准 | 实现 |
|---|---|---|---|
| 绝对辐射定标精度 | 角反射器 RCS 反演 vs 理论 RCS | GF-3：1.3~1.4 dB；S1C 实测 0.36 dB(1σ) | sct `rcs_error_[dB]`、gecoris |
| 辐射稳定性 / 长期漂移 | 雨林等稳定分布目标 γ⁰ 时序 | LT-1A：<1 dB/1000 km、<0.5 dB/5 天 | 自研 + 处理器版本元数据审计 |
| 跨轨天线方向图（EAP）残差 | 均匀场景列均值沿幅宽剖面 | 俯仰向增益 0.3 dB(1σ) | 自研（一维统计） |
| 子带 / 拼接辐射一致性 | 子带交界列均值阶跃 | 无台阶 | 自研；sentinel1denoised 参考 |
| 扇贝效应残差 | 方位向行均值周期性起伏 | 峰峰值 / 标准差(dB) | sct `scalloping` |
| 饱和率 / 动态范围 | 直方图上界堆积计数 | 饱和率 → 缺陷类 | 自研 |

### 维度 2 · 几何质量（5 项）

| 指标 | 测量方法 | 判据 / 基准 | 实现 |
|---|---|---|---|
| 绝对定位精度 ALE | 角反射器预测 vs 实测亚像素峰值 + 全改正 | S1C：均值 0.55 m / σ0.41 m；GF-3 带控 RMSE 2.56 m | sct（含 iono/tropo/潮/板块改正） |
| 相对定位 / 配准精度 | 互相关偏移；模拟幅度配准残差 | — | isce2/3、MintPy |
| 地形校正（RTC）正确性 | 局部入射角与散射面积一致性 | — | sarsen、isce3 |
| 叠掩阴影掩膜完整性 | DEM 正演掩膜 vs 产品掩膜比对 | — | sarsen、s1ard、OpenSarToolkit |
| 投影 / 采样间隔一致性 | 元数据 vs 栅格实际几何比对 | — | stac-check + 自研 |

### 维度 3 · 分辨率与点目标响应（5 项）

| 指标 | 测量方法 | 判据 / 基准 | 实现 |
|---|---|---|---|
| 空间分辨率（−3 dB） | 16× 过采样 IRF 主瓣半功率宽度 | 标称 / 实测 / 像素间距三者不可混用 | sct `range/azimuth_resolution_[m]` |
| PSLR 峰值旁瓣比 | 最高旁瓣 / 主瓣峰值 | 加权后 < −20 dB；GF-3 < −22 dB | sct `evaluate_pslr` |
| ISLR 积分旁瓣比 | 旁瓣积分能量 / 主瓣能量 | < −15 dB；GF-3 < −15 dB | sct `*_islr_[dB]`（含 2D） |
| SSLR 次生旁瓣比 | 非邻近旁瓣 / 主瓣 | — | sct（距/方/二维三向） |
| 散焦 / 展宽因子 | 实测 / 理论主瓣宽度之比 | 反映聚焦退化 | sct + 自研判据 |

> ⚠️ **引用陷阱**：PSLR 必须确认加权方式（ICEYE 均匀 −13.3 dB vs Taylor −20 dB 相差 7 dB）；ISLR 只有 TSX 附录 A 给出积分限才可复算；分辨率必须区分标称 / −3 dB / 像素间距。

### 维度 4 · 噪声与干扰（6 项）

| 指标 | 测量方法 | 判据 / 基准 | 实现 |
|---|---|---|---|
| NESZ | Doldrums 极低散射区交叉极化剖面 | TSX −19~−26 dB；GF-3 −20/−22 dB | sct `nesz`、xarray-sentinel（查表） |
| ENL / 辐射分辨率 | 均匀区矩估计 + 对数累积量估计（双估计量） | GF-3 辐射分辨率 3 dB | **自研（无现成库）** |
| AASR / RASR 模糊比 | 方位谱复制能量占比；鬼影识别 | TSX 方位 ≈−20 dB、距离 ≈−25 dB | sct 模糊比分析 |
| RFI 污染比例 | 距离频率—方位时间谱异常 + 行均值 3σ | 作为可用性标记，非合格判据 | **自研（无成熟实现）** |
| 去噪负值率 | 热噪声减除后负像素占比 | 过高 = 噪声高估，过低 = 未减除 | 自研；sentinel1denoised 参考 |
| 丢行 / 坏像元率 | 行列统计突变 + 无效值连通域 | A（大面积）/ D（零星） | 自研 |

### 维度 5 · 极化质量（5 项）

| 指标 | 测量方法 | 判据 / 基准 | 实现 |
|---|---|---|---|
| 通道幅度不平衡 | VV/HH 沿距离向比值 | S1C −0.5~+0.7 dB；LT-1A ≈0.2 dB | sct 极化分析 + 自研 |
| 通道相位不平衡 | 同极化相位差统计 | LT-1A ≈2° | 同上 |
| 交叉极化串扰 | 角反射器或分布目标反演串扰矩阵 | LT-1A < −35 dB；ALOS-2 实测 −38 dB | sct；参考 LT-1A 方法 |
| 互易性 VH≈HV | 两通道直方图与逐像素比对 | 单站 SAR 应统计一致 | **自研（低成本高信息量）** |
| 通道间配准 | 通道间互相关偏移 | — | 自研 |

### 维度 6 · 干涉与相位质量（5 项）

| 指标 | 测量方法 | 判据 / 基准 | 实现 |
|---|---|---|---|
| 相干系数分布 | 固定窗口相干估计（**必须报告窗口**） | 只对处理退相干设阈值 | sct、isce2/3、dolphin |
| 相位噪声标准差 | 高相干区相位离散度 | — | MintPy、gecoris |
| 解缠残差点密度 | 相位闭合（loop closure）残差 | 闭合残差 → 暴露解缠错误 | LiCSBAS、MintPy |
| 轨道残余斜坡 | 干涉图平面 / 二次曲面拟合系数 | — | MintPy、GMTSAR |
| 大气 / 电离层相位屏 | APS 估计与扣除后残差 | — | RAiDER、PyAPS、PySolid |

### 维度 7 · 完整性与元数据（6 项）

| 指标 | 测量方法 | 判据 / 基准 | 实现 |
|---|---|---|---|
| 有效数据覆盖率 | 有效像元 / 标称幅宽 | — | S1Tiling、自研 |
| 无效值 / 填充标识 | 掩膜 vs 实际无效区一致性 | B（未标记）/ D（已标记） | 自研 |
| 元数据字段齐备性 | 对照 CEOS-ARD Threshold / Goal 条款 | 逐条自评 | stac-check、s1ard |
| 定标常数可追溯 | 定标因子、辅助数据 / 处理器版本 | 版本台账审计 | 元数据审计 |
| 掩膜与不确定度层 | 是否提供逐像素质量层 | — | s1ard（CARD4L 注释层） |
| CARD4L 合规等级 | 逐条自评 Threshold / Goal | — | s1ard + 条款清单 |

## 四、分阶段实施路径

按成本递增原则分三期落地：

### 第一期 · 低成本全量前置筛查（覆盖 100% 数据，成本可忽略）

纯一维 / 直方图级统计，不依赖角反射器或已知坐标：

- 方位向行均值剖面 → 扇贝残差
- 距离向列均值剖面 → 子带台阶、EAP 残差
- 直方图上界堆积 → 饱和率
- 负值率 → 热噪声减除健康度
- 无效值连通域 → 丢行 / 坏像元
- VH/HV 互易性 → 通道问题（高信息量、低成本）

### 第二期 · sct 引擎核心物理指标（有条件数据，SLC 级）

以 `aresys-srl/sct` 为底座，配 `sct_plugins` 多传感器读取。直接获得：IRF 分辨率、PSLR / ISLR / SSLR、RCS / SCR、ALE（含全改正）、NESZ、扇贝、模糊比。字段命名与默认参数（过采样 16×、ROI [128,128]、相干核 [15,15]）作为规格对齐基准，避免重定义指标。

### 第三期 · 自研补缺模块 + 元数据合规

- **去斑 / 降噪评价指标包**（空白 1）：均匀区自动筛选 + ENL 双估计量 + 比值图白噪声检验 + EPD-ROA，以 Raydonal/UNASSISTED 的 M-index 为对齐基准，纯 numpy 可完成。
- **RFI 谱域检测器**（空白 2）：距离频率—方位时间谱 + 行统计异常 + 污染比例输出，以 SAR-IIDS / RFISD 为基准，ESA s1rfimap 作外部交叉校验。
- **元数据规则引擎**：stac-check 规则结构 + CEOS-ARD 条款清单，逐条输出 Threshold / Goal 自评。

## 五、判定与缺陷分级机制（连续量 → 离散判决的接口）

把物理指标接入法定验收流程的核心设计：

1. **超差比例转换**：某质检项超出规格的像元 / 子块 / 观测占比 → 缺陷类

   | 超差比例 | 缺陷类 | 扣分 | 判定 |
   |---|---|---|---|
   | > 5% | A（严重） | 42 分 | 样本出现即整批不合格 |
   | 3.75%–5% | B（重） | 12 分 / 处 | — |
   | 2.5%–3.75% | C（次重） | 4 分 / 处 | — |
   | 1.67%–2.5% | D（轻） | 1 分 / 处 | — |

2. **百分制扣分**：`S₂ = 100 − (12a₁ + 4a₂ + a₃) / t` → 优 ≥ 90 / 良 75–90 / 合格 60–75 / 不合格 < 60。
3. **抽样量表**（GB/T 24356-2023）：批量 1–20 → 样本 3 … 687–1000 → 样本 56，抽样比由 15% 递减至 5.6%，≥ 1001 须分批。
4. **判决项 vs 标记项分离**：RFI 污染比例、叠掩阴影占比、低相干区占比是**场景相关退化**，只作可用性元数据随产品发布，由下游决定接受与否；只有系统性能（分辨率 / NESZ / 模糊比）与产品正确性（定标 / 地理编码 / 掩膜 / 元数据）做合格性判决。

## 六、关键工程约束

1. **阈值与版本绑定存储，不写死在代码里**：处理器 / 辅助数据版本升级会产生系统性误报（如 S1B 方位分辨率变更、S1C 22° 视角 SLC 才出现的 1.8 m 偏移）。质检报告须记录"用的哪一版规范哪一条"。
2. **许可合规**：sentinel1denoised / gecoris / LiCSBAS / s1tbx 为 GPL-3.0 只宜研读；isce2/3 / MintPy / dolphin 为 NOASSERTION 需核对；IQA-PyTorch 含非商业条款。
3. **ENL 必须成对使用**：ENL 与边缘保持度（EPD-ROA）成对报告，否则过度平滑会刷高 ENL 却毁掉分辨率；双估计量分歧 = 区块不够均匀的告警。
4. **数据量大勿克隆**：snap-engine / s1tbx / isce3 等改用 conda-forge / PyPI 安装或在线浏览源文件。

## 七、验证与消融闭环

任何新规则上线前走四步消融协议：

1. 基准线（不带该规则）
2. 加入规则
3. 下游指标对比（检测精度、时序一致性、下游应用性能）
4. 记录被删样本另存，可回溯

持续用**分组留存率审计**监控每类缺陷的检出率随版本漂移，防止阈值老化。

## 一句话总结

> 以 sct 为物理指标底座 + 自研去斑评价 / RFI 检测 / 元数据规则三模块补齐空白，按"低成本全量筛查 → 物理指标测量 → 合规判定"三级落地，用"超差比例 → A/B/C/D"接口把 7 维 38 项连续指标接入 GB/T 24356 的法定验收框架，并保留消融闭环作为持续演进机制。

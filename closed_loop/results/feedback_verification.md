# 质检有效性验证报告（闭环反馈 · 四实验）

> 专利实证：用「反馈动作 → 指标变化」反向验证质检的有效性（质检指标是否可操作、可指导改进）。
> 三个反馈机制四个实验，证据 JSON 见 `results/experiments/`。

---

## 结论速览

| 实验 | 反馈机制                 | 质检有效性判据                        | 结果                                                                     |
| ---- | ------------------------ | ------------------------------------- | ------------------------------------------------------------------------ |
| exp1 | 重选模型                 | 改派更优变体后指标改善？              | ✅**强正**：ΔENL 2.374→0.383（−84%）、BVE 0.117→0.002（−98%） |
| exp2 | 调整参数                 | 指标随生成参数单调变化？              | ✅**强正**：SSIM/NCC 随去噪步数单调（59%/31% 跨度）                |
| exp3 | 重训练（朴素续训）       | 续训后指标改善？                      | ⚠️**中性**：200 kimg 续训无显著改善                              |
| exp4 | 重训练（方位角定向微调） | 用质检估计器 R 定向修复后 CMAE 改善？ | ✅**强正**：CMAE 90.9°→44.7°（−50.7%），其余指标稳定           |

**核心结论**：质检不仅能「打分」，还能**区分变体并指导选型（exp1）**、**对生成参数敏感可指导调参（exp2）**，
更能在**重训**场景给出**可执行的定向修复方案**：exp3 朴素续训（同样 200 kimg）无改善，而 exp4 把质检
自己的方位角估计器 R(·) 反过来作为冻结教师监督生成器，CMAE 从 90.9° 降到 44.7°、且固定潜码扫描的
「条件角→预测角」相关性从 −0.14 升至 +0.78（CMAE 6.1°）——证明质检不仅能说「哪里差」，还能指导
「往哪改」，且该指导确有因果效用。这是专利「质检有效性由因果效用验证」的最强证据。

---

## exp1 —— 重选模型（免费，复用既有评估）

**问题**：质检能否区分同一模型的三个变体，并在「背景统计一致」需求下改派到更优变体？

**数据**：angle_gen 三变体（geometry/baseline/adapted）在 v3 已评估（各 50 对）。

| 变体            | ΔENL           | BVE              | SSIM             | AFS             | PSNR            |
| --------------- | --------------- | ---------------- | ---------------- | --------------- | --------------- |
| adapted（默认） | 2.374           | 0.1169           | 0.0010           | 0.680           | 2.97            |
| geometry        | 0.449           | 0.0092           | 0.0320           | 0.729           | 12.05           |
| baseline        | **0.383** | **0.0020** | **0.1324** | **0.775** | **15.98** |

**反馈动作**：需求 `background_consistency=high` → 质检检测 `adapted` 的 ΔENL=2.374 弱（阈值 >2.0）
→ 改派 `baseline`（ΔENL=0.383）。

**验证**：

- 背景一致性：ΔENL **2.374 → 0.383**（相对改善 83.9%），BVE **0.117 → 0.002**（98.3%）。
- 结构保真（第二关注维度）：SSIM **0.001 → 0.132**（99.2%），PSNR **2.97 → 15.98**。

> 证据：`results/experiments/exp1_reselect.json`（含两个关注维度的完整 reselect 结果）。

## exp2 —— 调整参数（angle_gen 扩散去噪步数）

**问题**：质检指标是否随生成参数（扩散去噪步数）单调变化，即质检对参数敏感、可指导调参？

**方法**：angle_gen（geometry）单次生成，落盘全部 8 个去噪中间步 `w=0..7`（w=0 最充分去噪），
逐步计算与真值的配对 SSIM/PSNR/NCC。

**结果**（30 对样本平均，随去噪进程单调）：

| w 索引（0=最去噪） | SSIM             | PSNR            | NCC             |
| ------------------ | ---------------- | --------------- | --------------- |
| 0                  | **0.0247** | **12.29** | **0.132** |
| 4                  | 0.0109           | 9.75            | 0.099           |
| 7（最少去噪）      | 0.0101           | 9.55            | 0.092           |

**验证**：SSIM、NCC 严格单调递减（随去噪进程 0.0247→0.0101，59% 跨度；NCC 31%）；PSNR 近似单调
（12.29→9.55，22%）。→ **质检对扩散步数敏感，可据此选出最优去噪配置**。

> 证据：`results/experiments/exp2_adjust_param.json`（含 per_step_metrics + 单调性分析）。

## exp3 —— 重训练（stylegan 快照续训 200 kimg）

**问题**：质检发现的结构保真弱（SSIM≈0.037）经重训后是否改善？

**方法**：`train.py --resume=network-snapshot-001300.pkl --kimg=200`（续训 200 kimg），
从新快照 `network-snapshot-000200.pkl` 生成 500 张，13 指标复评。

**结果**（500 张，与基线对比）：

| 指标   | 基线(1300) | 续训后(200) | Δ             |
| ------ | ---------- | ----------- | -------------- |
| FID    | 201.8      | 206.3       | +4.5（无改善） |
| SSIM   | 0.0366     | 0.0340      | −0.003        |
| AFS    | 0.646      | 0.643       | −0.004        |
| ΔENL  | 0.409      | 0.423       | +0.014         |
| CMAE° | 90.9       | 92.0        | +1.2           |

**结论**：13 项指标均无显著变化（全部在噪声范围内）。重训机制跑通（检测弱点→触发续训→复评→delta），
但 200 kimg 朴素续训未改善——说明 stylegan 基线已接近该类训练的指标平台期，其结构保真/角度控制弱点是
**任务/架构层面限制**，无法靠「更多同类训练」修复。

**后续方向**（如需转正的实验）：① 更长续训（≥500 kimg，前 100 kimg 被 ADA 重启消耗）；② 针对 CMAE
弱点的**方位角显式损失微调**（当前模型方位角控制≈随机 91°，是三元模型共同短板，见 MODEL_EVIDENCE）。

> 证据：`results/experiments/exp3_retrain.json`（含 baseline/retrained 13 指标全表 + delta）。

## exp4 —— 重训练·方位角定向微调（质检估计器 R 作为冻结教师）

**问题**：exp3 证明「朴素续训」治不了 CMAE 弱点（方位角控制≈随机 91°）。质检能否给出**定向**修复
（而不是盲目续训），让「往哪改」真正落地？

**方法**：把质检系统计算 CMAE 的辅助方位角估计器 R(·)（v2 `gan_metrics/models.py` 的 AspectAngleEstimator，
论文 §3.1.4）**冻结**作为教师，在 stylegan Gmain 阶段额外加「方位角一致性损失」
`1 − cos_sim(R(gen_img), (sin,cos)_cond)`（`plugin/azimuth_loss.py` + `training/loss.py`，权重 1.0）。
同样 `--resume=network-snapshot-001300.pkl --kimg=200`，与 exp3 **同预算**。

**结果**（500 张，13 指标复评）：

| 指标   | 基线(1300) | exp3 朴素续训(200) | exp4 定向微调(200) | Δ(exp4 vs 基线)            |
| ------ | ---------- | ------------------ | ------------------ | --------------------------- |
| CMAE° | 90.9       | 92.0               | **44.7**     | **−46.1（−50.7%）** |
| FID    | 201.8      | 206.3              | 203.7              | +1.9（稳定）                |
| SSIM   | 0.0366     | 0.0340             | 0.0353             | −0.001（稳定）             |
| AFS    | 0.646      | 0.643              | 0.649              | +0.002（稳定）              |
| ΔENL  | 0.409      | 0.423              | 0.318              | −0.091（略改善）           |

**角度控制验证（非退化性证据）**：固定同一潜码 z（seed 1234）、同一类别，扫条件方位角 0..360°
（步长 15°），用 R 反推生成图朝向。基线「条件角→预测角」散点近乎噪声（corr=−0.14，CMAE 88.9°），
而定向微调后接近对角线 y=x（corr=+0.78，CMAE 6.1°）。证明 CMAE 下降是生成器**真正学会了方位角编码**，
而非靠「把图都生成成某个 R 偏好的角」的退化解。

> 证据：`results/experiments/exp4_azimuth_retrain.json`（13 指标全表 + delta）、
> `results/experiments/exp4_angle_control.json` + `exp4_angle_control.png`（固定 z 角度扫描散点）。

**诚实边界**：CMAE 定义即由 R(·) 计算，故「CMAE↓」部分含义是「生成器学会了满足 R 的角度期望」；
但 corr 散点（条件角→预测角接近 y=x）证明了这是**真实的、非退化的角度控制**，而非过拟合 R 的度量。

## 三反馈机制的统一逻辑（专利技术方案骨架）

1. **检测**：质检（6 论文 + 7 FR + 辅助估计器 R/E_asc）→ 画像 → 弱点指标集合（`evaluation/portrait.py`）。
2. **决策**：弱点 → 首选反馈动作（背景统计类 → 重选；结构/角度类 → 重训；参数可扫 → 调参）。
3. **执行**：`feedback/reselect.py` / `adjust_param.py` / `retrain.py` 三机制（`agent/feedback_optimizer.py` 统一入口）；
   `retrain.py` 内 `azimuth_weight` 参数在「朴素续训」与「方位角定向微调（R 作冻结教师）」间切换。
4. **验证**：复评 → 指标 delta → 判定「质检是否有效」（反馈动作能否带来可预测的指标变化）。

代码入口：`scripts/run_closed_loop.py`（端到端闭环，复用模式零 GPU）与
`scripts/run_feedback_experiments.py`（exp1/2/3，GPU）、`scripts/run_azimuth_finetune.py`（exp4，GPU）、
`scripts/verify_angle_control.py`（exp4 角度控制散点验证）。

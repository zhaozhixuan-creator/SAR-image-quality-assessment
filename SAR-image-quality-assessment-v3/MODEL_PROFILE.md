# SAR 生成模型画像（v3）

> **用途**：供「需求解析侧」把一条自然语言生成需求映射到可执行模型。
> 本文是**能力画像**，只回答「哪个模型能做哪种任务」，不含指标数值（指标见 [MODEL_EVIDENCE.md](MODEL_EVIDENCE.md)）。
> **数据口径**：v3 流水线 generate→align→evaluate→report 实测（stylegan 5 类 500 张 / angle_gen 3 变体各 50 对 / frequency_gen 99 对）。

---

## 0. 一句话结论

三个模型对应**三个基本不重叠的任务类型**，不是「同一任务上的三个模型」：

| 模型              | 任务类型                                        | 关键边界                        |
| ----------------- | ----------------------------------------------- | ------------------------------- |
| `stylegan4sar`  | 类 + 方位角条件**批量生成**（无需参考图） | 仅 5 类、128×128、不保实例     |
| `angle_gen`     | 参考图驱动**新视角合成**（NVS，保实例）   | 10 类、64×64、需参考图、扩散慢 |
| `frequency_gen` | X→Ka**跨波段翻译**（配对逐像素）         | 无类别/角度、仅 X→Ka 这一域对  |

## 2. 模型画像

### 2.1 stylegan4sar —— 类级批量生成（5 类）

- **定位**：StyleGAN2-ADA 基线，按「类别 + 方位角」条件采样，**不需要参考图**。
- **条件输入**：`class ∈ {2S1, BRDM2, D7, T62, ZIL131}` + 方位角 `az`（条件向量 `[onehot(5), sin(az), cos(az)]`）。
- **输出**：128×128 单通道灰度 PNG；每类任意数量（实测 100/类 ×5 = 500 张）。
- **能做什么**：
  - 5 类内的「为 X 生成 N 张」批量生成（BG07）。
  - 方位角单角 / 范围间隔 / 边界 / 负角 / 超一周——条件用 sin/cos 天然处理环形（AZ 语义上全部接受）。
- **不能做什么**：
  - 10 类里的 BMP2、BTR60、BTR70、T72、ZSU234（原始模型只训了 5 类）。
  - 参考图换视角 / 保持具体实例结构（类级随机 z，不保实例）。
  - 俯仰角 / 入射角、极化、3D 模型、背景合成、CFG、LoRA。
- **关键证据**（详见 [MODEL_EVIDENCE.md](MODEL_EVIDENCE.md)）：
  - 背景统计一致性较好：ΔENL≈0.41、BVE≈0.011。
  - 结构保真弱：SSIM≈0.037、AFS≈0.646。
  - **方位角控制弱**：CMAE≈91°（接近随机）；经「方位角定向微调」变体 `stylegan2_ada_5class_azimuth`
    （closed_loop exp4，质检估计器 R 作冻结教师）可降至 ≈44.7°，属**部分缓解**而非精确控制。

### 2.2 angle_gen —— 参考图驱动新视角合成（10 类，保实例）

- **定位**：XUNet 扩散 NVS，给一张参考 SAR 图 + 目标角度，合成**同一目标**的新视角。
- **条件输入**：参考图 + 方位角(src→tgt) + 入射角(src→tgt)；三变体 `geometry`（真几何姿态）/ `baseline`（针孔代理）/ `adapted`（geometry 同构的另一权重）。
- **输出**：64×64 单通道 NPY；10 类全量。
- **能做什么**：
  - 参考图换视角、保持散射结构（RF01/RF02/RF03）。
  - 单参考视角插值 / 大角外推（VC01/VC02/VC03，外推有 OOD 风险）。
- **不能做什么**：
  - **无参考**的「按类别批量生成」（依赖数据集配对 test loader，不能凭空按类造图）。
  - 双参考视角融合（RF06）、混合实例输入（VC06）。
  - RGB 直接输入需先转单通道（RF07）；缺角度元数据无法条件（RF08）。
  - 低显存 / 低延迟场景：256 步扩散 ≈65s/样本。
- **关键证据**：AFS 0.68–0.78、ΔENL 0.38–0.45（除 adapted 的 ΔENL≈2.37 偏弱）；FR 逐像素指标天然低（NVS 是合成新视角，非重构）。三变体里 `baseline` 结构/统计指标最稳。

### 2.3 frequency_gen —— X→Ka 跨波段翻译

- **定位**：Pix2Pix + SAR `pdfLoss`，把 X 波段整图翻译成 Ka 波段，**配对逐像素**任务。
- **条件输入**：X 波段整图（无类别、无角度）。
- **输出**：整图（真实 wholeImg 测试集 99 对）。
- **能做什么**：X→Ka 跨波段翻译（DM03），仅此一种域对。
- **不能做什么**：类别/角度条件生成；极化通道选择；其他域迁移（星载→机载、仿真→实测、数据集间等均无模型）。
- **关键证据**：FR 保真度是三者最高——SSIM≈0.617、PSNR≈20.1、FSIM≈0.778、NCC≈0.521（因为是真·配对翻译，与生成式模型的 FR 天然不同量级，**不可跨模型直接比**）。

## 3. 当前不覆盖（需求解析侧应直接拒绝或降级）

以下需求形态当前**没有任何模型支持**，解析到即应明确告知不可执行：

- **极化条件生成**（PL01–PL05、SAGA01）——无极化模型。
- **三维模型 / 雷达参数驱动生成**（PS01–PS06、SAGA02/SAGA05）——无 3D 输入。
- **目标与背景合成**（CP01–CP05、SAGA07）——无合成模型。
- **俯仰角独立控制**（EL 系列）——只有 angle_gen 的入射角条件，俯仰角不可独立控。
- **CFG / LoRA**（FM03/FM04）——无 CFG、无 LoRA 微调流程。
- **下游分类训练验证**（QL08）——无分类器训练回路。
- **复杂 I/Q / 相位物理输出**（PS06）——只输出幅度灰度图。

## 4. 关键警告（需求解析侧必须知道）

1. **「方位角可控」对基线是假阳性、对微调变体是部分缓解**：三个模型基线都**接受**方位角作为条件输入，但实测生成图方位角误差 CMAE 普遍 64°–102°（R 估计器在真实图自检仅 22° 左右，故这是模型真实短板而非测量噪声）。唯一例外是 stylegan 的方位角定向微调变体（closed_loop exp4，把质检估计器 R 冻结作教师），CMAE 降至 ≈44.7°，把方位角从「接近随机」拉到「大致可控」——但**仍非精确控制**（44.7° ≫ R 自检 22°）。**精确到某角度的需求仍应拒绝或降级**为「近似方位角多样性，可选微调变体」。
2. **FR 逐像素指标不可跨模型直接比**：frequency_gen 是配对翻译（FR 天然高），stylegan/angle_gen 是生成式合成（FR 天然低）。跨模型比较只认「同任务」下的相对值，不认绝对 FR。
3. **FID 有离线回退风险**：FID 用 torchvision Inception-v3，离线时回退随机初始化（仅流程演示，绝对值不可作结论）。
4. **stylegan 的 5 类限制**是硬边界，不是可调参数——10 类请求中除 `2S1/BRDM2/D7/T62/ZIL131` 外一律只能走 angle_gen 的「参考图换视角」路径，无法「无参考批量生成」。

## 5. 质检反馈决策（闭环：质检发现问题后怎么修）

> 上表 §1 回答「用哪个模型做哪个任务」（**选型**）；本节回答「质检发现质量问题后怎么修、预期改善多少」（**反馈**）。
> 规则实现于 `closed_loop/`（`evaluation/portrait.py` 阈值 + `feedback/{reselect,adjust_param,retrain}.py` 机制），
> 实测效果见 `closed_loop/results/feedback_verification.md`。这是专利「质检不仅说哪里差、还指导往哪改」的**决策层**。

### 5.1 质量需求 → 指标映射

| 需求维度（`quality_requirements`）        | 对应指标     | 方向       |
| ----------------------------------------- | ------------ | ---------- |
| `background_consistency`（背景统计一致）  | ΔENL、BVE    | ↓ 越小越好 |
| `structure_fidelity`（结构保真）          | SSIM、AFS    | ↑ 越大越好 |
| `azimuth_precision`（方位角精度）         | CMAE°        | ↓ 越小越好 |

### 5.2 弱点检测阈值（绝对阈值，与 v3 `stage_report` 同口径）

| 指标 | 判「弱」阈值 | 判「强」阈值 | 弱点归属 |
| ---- | ------------ | ------------ | -------- |
| SSIM | < 0.35       | ≥ 0.6        | 结构保真 |
| AFS  | < 0.7        | ≥ 0.9        | 散射结构 |
| ΔENL | > 2.0        | < 0.5        | 背景统计 |
| BVE  | > 0.05       | —            | 背景统计 |
| NCC  | < 0.2        | ≥ 0.5        | 结构保真 |
| CMAE | ≥ 45°        | —            | 方位角   |

> 阈值为**经验口径**（从 v3 `pipeline/stage_report.py` 提炼，与 `closed_loop/evaluation/portrait.py` 同源），
> 非统计校准值；其用途是给「弱点 → 动作」一个稳定、可复现的判定，而非追求最优分类边界。

### 5.3 弱点 → 反馈动作决策

```
质检画像 → 弱点指标集合
   ├─ 含 ΔENL / BVE（背景统计类）→ reselect：改派同模型内该维度更优变体（显著阈值：相对差 ≥5%）
   └─ 否则（结构/角度类）        → retrain：朴素续训，或方位角定向微调（质检估计器 R 作冻结教师）
```

- **reselect**（`closed_loop/feedback/reselect.py`）：在候选变体间挑关注维度最优者，`相对差 ≥5%` 才判定显著改派；同时给出 `expected.relative_gap`（预期改善幅度）。
- **adjust_param**（`closed_loop/feedback/adjust_param.py`）：扫单模型生成参数（如扩散去噪步数），指标随参数**单调变化**即证明质检对参数敏感、可指导调参，并给出 `best_param`。
- **retrain**（`closed_loop/feedback/retrain.py`）：`azimuth_weight>0` 时把质检估计器 R(·) 冻结作教师、加方位角一致性损失（定向微调），否则为朴素续训。

### 5.4 实测反馈效果（四实验，证据见 `closed_loop/results/experiments/`）

| 实验 | 反馈动作                        | 结果                                              |
| ---- | ------------------------------- | ------------------------------------------------- |
| exp1 | 重选：adapted → baseline        | ΔENL 2.374→0.383（−84%）、BVE 0.117→0.002（−98%） |
| exp2 | 调参：扩散去噪步数              | SSIM/NCC 随步数单调（质检对参数敏感）             |
| exp3 | 重训：朴素续训 200 kimg         | 中性（无显著改善）                                |
| exp4 | 重训：方位角定向微调（R 作冻结教师） | CMAE 90.9°→44.7°（−50.7%），其余指标稳定        |

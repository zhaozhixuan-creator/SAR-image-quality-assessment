# SAR 生成模型评估证据（v3 · 带数据）

> 本文是 [MODEL_PROFILE.md](MODEL_PROFILE.md) 的**证据层**：字段定稿、13 项指标实测值、配对口径、辅助估计器自检，以及按《SAR 常见生成需求场景与模型能力压力测试用例》逐类筛选的测试结果。
> **实测规模**：stylegan 5 类 ×100=500 张、angle_gen 3 变体 ×50 对、frequency_gen 99 对。

---

## 1. 字段定稿

| 字段               | 含义                                  | 方向        | 适用                 |
| ------------------ | ------------------------------------- | ----------- | -------------------- |
| `fid`            | Fréchet Inception Distance（分布级） | ↓ 越小越好 | stylegan / angle_gen |
| `ssim`           | 结构相似度（配对）                    | ↑ 越大越好 | 全部                 |
| `afs`            | 目标区散射结构一致（ASC）             | ↑ 越大越好 | stylegan / angle_gen |
| `delta_enl`      | 背景等效视数偏差（ΔENL）             | ↓ 越小越好 | stylegan / angle_gen |
| `bve`            | 背景方差误差（BVE）                   | ↓ 越小越好 | stylegan / angle_gen |
| `cmae_deg`       | 循环平均绝对方位角误差（°）          | ↓ 越小越好 | stylegan / angle_gen |
| `mse` / `rmse` | 均方误差 / 均方根误差                 | ↓ 越小越好 | 全部                 |
| `psnr`           | 峰值信噪比                            | ↑ 越大越好 | 全部                 |
| `ncc`            | 归一化互相关                          | ↑ 越大越好 | 全部                 |
| `uqi`            | 通用图像质量指标                      | ↑ 越大越好 | 全部                 |
| `ms_ssim`        | 多尺度 SSIM                           | ↑ 越大越好 | 全部                 |
| `fsim`           | 特征相似度                            | ↑ 越大越好 | 全部                 |

> 口径：输入统一为幅度域 [0,1] 灰度图；ΔENL/BVE 在强度域（幅度²）计算；`rmse = √mse`。
> frequency_gen（翻译任务）无分布/角度域，仅适用 `ssim + 7 项 FR`，故 FID/AFS/ΔENL/BVE/CMAE 置空。

**读数要点**：

- **frequency_gen** 是唯一「真·配对翻译」，FR 全面最高（SSIM 0.617 / FSIM 0.778 / PSNR 20.1）——这是任务本质，不代表它「更好」，只代表 FR 这类逐像素指标对翻译任务天然友好。
- **stylegan / angle_gen** 是生成式合成，FR 天然低（SSIM 0.001–0.13），应看物理/分布指标：stylegan 背景统计好（ΔENL 0.41 / BVE 0.011），angle_gen `baseline` 结构/统计最稳（AFS 0.775 / ΔENL 0.383 / BVE 0.002），`adapted` 明显偏弱（ΔENL 2.37 / PSNR 2.97）。
- **CMAE 基线全线偏高**（64°–102°），见 §4 自检结论：不是估计器噪声，是模型方位角控制弱。唯一例外：stylegan 的方位角定向微调变体（closed_loop exp4，质检估计器 R 作冻结教师）CMAE 降至 44.7° 且其余指标稳定，但相对 R 自检 22° 仍非精确控制。

## 3. 配对口径（FR 逐像素指标语义）

| 模型          | 配对方式                                             | FR 语义                 |
| ------------- | ---------------------------------------------------- | ----------------------- |
| stylegan4sar  | 跨样本同类配对：按条件方位角在真实同类样本中取最近角 | 非逐像素重构，FR 偏保守 |
| angle_gen     | 真·新视角合成：NVS 目标视角 vs 对应真值             | FR 偏低是任务本质       |
| frequency_gen | 翻译配对：生成 Ka vs 真值 Ka 逐像素                  | FR 直接反映翻译保真度   |

## 4. 辅助估计器自检

| 估计器                       | 在真实测试集自检 CMAE | n    |
| ---------------------------- | --------------------- | ---- |
| R_128（128×128 方位角估计） | 22.19°               | 2425 |
| R_64（64×64 方位角估计）    | 16.09°               | 2425 |

> 结论：R 估计器本身可信（真实图误差 ≤22°）。因此生成图 CMAE 60°–102° 是**模型真实短板**，非测量噪声。经方位角定向微调（closed_loop exp4，R 作冻结教师）后 stylegan 的 CMAE 可降至 44.7°——证明该短板**可被定向修复**，但仍高于 R 自检 22°，未达精确控制。

## 6. 汇总：真正能「实测」的三条主线

1. **类 + 方位角条件批量生成** → stylegan（限 5 类）。
2. **参考图驱动新视角合成** → angle_gen（限 10 类、需参考）。
3. **X→Ka 跨波段翻译** → frequency_gen（限 X→Ka 域对）。

其余约 2/3 场景（极化、3D、背景合成、俯仰角独立、CFG/LoRA、下游分类、双参考、低显存扩散）当前无模型覆盖。

# SAR常见生成需求场景与模型能力压力测试用例

本文档只整理用户需求场景、请求类型和自然语言测试用例，不预先指定适合的模型。后续将使用这些请求分别测试五个模型，再根据实际结果形成模型画像。

## 1. SAGA中提炼的典型用户需求问题

| 编号   | 需求场景                       | 用户核心问题                                        | 简化请求例子                                                                |
| ------ | ------------------------------ | --------------------------------------------------- | --------------------------------------------------------------------------- |
| SAGA01 | 极化条件生成                   | 如何利用全极化SAR数据生成指定极化条件的目标图像？   | 检查全极化车辆数据ZJGC-X，使用LoRA训练带极化条件的扩散模型，生成100张图像。 |
| SAGA02 | 三维与雷达参数驱动的全方位生成 | 如何根据三维模型和雷达成像参数生成全方位SAR视图？   | 我提供三维车辆模型和雷达成像参数，生成0°到360°的SAR图像，方位角间隔5°。  |
| SAGA03 | 快速低资源批量生成             | 如何在显存有限时快速生成大量类别样本？              | 快速生成500张2S1目标图像，显存不超过10GB，生成速度优先。                    |
| SAGA04 | 稀疏视角补全                   | 如何根据少量已知方位角图像补齐缺失视角？            | 根据BTR70的稀疏视角SAR图像，快速补齐缺失方位角。                            |
| SAGA05 | 三维先验辅助的大角度补全       | 如何利用SAR图像和三维模型完成大角度视角外推？       | 使用B747的SAR图像和三维飞机模型，生成缺失方位角和俯仰角下的目标图像。       |
| SAGA06 | 跨平台或跨域迁移               | 如何在保持目标结构的同时迁移不同平台的SAR数据特征？ | 将星载SAR数据的特征迁移到机载SAR图像，同时保持目标结构。                    |
| SAGA07 | 目标与背景合成                 | 如何将目标切片与指定SAR背景组合成新场景？           | 将舰船目标合成到随机SAR水面背景中，保持舰船清晰可见并保留水体杂波纹理。     |

## 2. 按需求类别展开的测试用例

### 2.14 表述鲁棒性

同组请求应被解析为相同或等价需求，但不预设最终模型结果。

| 组 | 请求变体                                                                        |
| -- | ------------------------------------------------------------------------------- |
| P1 | “为BMP2生成100张。” / “给BMP2造一百幅。” / “Generate 100 BMP2 SAR chips.” |
| P2 | “生成35°BMP2。” / “观察角35度的BMP-2。” / “BMP2 at 35-degree azimuth.”   |
| P3 | “照着这张图转到35°。” / “保持同一目标，只换观察角。”                       |
| P4 | “不要保持原图实例，只要同类多样样本。” / “Class-level variation is enough.” |
| P5 | “扩散模型类别生成。” / “class-conditional diffusion sampling.”              |
| P6 | “最终只要8张。” / “改成8幅。” / “only generate 8 samples.”                |

以上用例只定义需求，不包含模型能力结论。五个模型完成相同场景测试后，再根据实际成功状态、输出结果和资源表现判断适用范围。

> 对应调研空白 1。唯一有权威参考实现的是 M-index（Raydonal/UNASSISTED），但未进入任何机构业务化质检链。均匀区 ENL、EPD-ROA、DG、比值图空间统计没有维护中、可 pip 安装的统一实现——**指标数量有限、定义清晰、纯 numpy 可完成，是最值得自研的模块**。

## 1. 需求背景

去斑是 SAR 处理链最常见的增强步骤，也是最难客观评价的一步——因为**不存在无斑点的参考图像**。把 PSNR / SSIM 直接搬过来会得到严重误导性结论：过度平滑在这些指标上往往得分更高，而分辨率与纹理已被破坏。

核心判据思想：**理想去斑的比值图（含斑 / 去斑）应为纯斑点**，不含任何残留地物结构。过度平滑的比值图中清晰可见地物轮廓，说明有用信号被误当噪声滤除。

## 2. 指标集

| 指标 | 含义 | 方向 | 陷阱 |
|---|---|---|---|
| ENL（均匀区） | 斑点抑制程度 | 越大越好 | 过平滑刷分；依赖区块选取 |
| 比值图白噪声检验 | 均值 / 方差与理论一致，且空间无结构 | 越接近理论越好 | 仅看均值方差不够，需配空间自相关检验 |
| EPD-ROA | 边缘保持度（边缘两侧比值） | 越接近 1 越好 | 依赖边缘检测稳定性 |
| DG（Despeckling Gain） | 综合去斑增益 | 越大越好 | 需参考图像，实测数据难用 |
| M-index / α-β | 无参考综合度量 | 越小越好 | 有权威参考实现（UNASSISTED） |

**关键工程原则**：ENL 与 EPD-ROA 必须**成对报告**——过度平滑会得到极高 ENL，却同时毁掉分辨率与边缘。单看任一指标都会得出错误结论。

## 3. 算法设计

### 3.1 均匀区自动筛选（前置步骤）

用局部变异系数（CV）图筛选均匀区，剔除纹理区与边缘。

```python
import numpy as np
from scipy.ndimage import uniform_filter

def uniform_mask(image, win=7, cv_max=0.1):
    """
    基于局部变异系数筛选均匀区。
    image: 强度图像（非 dB）
    返回布尔掩膜：True 为均匀区
    """
    mean = uniform_filter(image, size=win)
    sq_mean = uniform_filter(image**2, size=win)
    var = np.maximum(sq_mean - mean**2, 0)
    cv = np.sqrt(var) / np.maximum(mean, 1e-6)
    return cv < cv_max
```

### 3.2 ENL 双估计量

```python
from scipy.special import polygamma

def enl_moment(I, mask):
    """矩估计：ENL = mu^2 / sigma^2（均匀区最优，对纹理敏感）"""
    x = I[mask]
    mu = x.mean()
    var = x.var()
    return (mu**2) / var

def enl_logcumulant(I, mask):
    """对数累积量估计：由 Var[log I] = psi_1(L) 反解 L（对纹理更稳健）"""
    t = np.log(I[mask])
    v = t.var()
    # 反解：psi_1(L) = v，用二分/迭代求 L
    lo, hi = 1e-3, 1e3
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        if polygamma(1, mid) > v:
            hi = mid
        else:
            lo = mid
    return 0.5 * (lo + hi)
```

**判据**：`enl_moment` 与 `enl_logcumulant` 出现明显分歧 → 所选区块不够均匀，须重新筛选。

### 3.3 比值图白噪声检验

```python
def ratio_image_test(I_speckled, I_denoised):
    """比值图应逼近纯斑点（指数分布，无空间结构）"""
    R = I_speckled / np.maximum(I_denoised, 1e-6)
    # 一阶：均值应 ≈ 1
    mean_ok = abs(R.mean() - 1.0)
    # 二阶：方差应与理论一致
    var_theory = 1.0  # 单视比值图指数分布 var = 1
    var_ok = abs(R.var() - var_theory)
```

### 3.5 M-index（无参考综合）

以 Raydonal/UNASSISTED 为对齐基准。M-index 把比值图的一阶统计偏差与残留结构（GLCM 纹理泄漏）合成单一分数，越小越好。权威定义见 Gomez / Ospina / Frery 2017。

## 4. 实现建议

1. **对齐基准**：以 UNASSISTED 的 M-index 为基准，把剩余指标（均匀区 ENL 双估计量、比值图白噪声检验、EPD-ROA）补齐成一个包。
2. **纯 numpy**：指标定义清晰，无需深度学习，`pip` 可安装。
3. **复用面**：一旦实现即可复用于所有去斑 / 降噪算法的横向评测（deepdespeckling 等）。
4. **基线算法**：hi-paris/deepdespeckling（MERLIN + SAR2SAR 预训练权重）可作为基线算法对比。

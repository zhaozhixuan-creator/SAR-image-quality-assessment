# 维度 4 · 噪声与干扰

> 判据来源：低散射参考区与谱域分析。本维度 6 项指标覆盖斑点噪声、系统灵敏度、模糊与射频干扰，是 SAR 与光学差异最大的一类。

## 4.1 维度定位

SAR 是相干成像，斑点（speckle）不是"噪声污染"而是信号本身的统计性质；系统灵敏度由热噪声与处理增益决定；PRF 约束派生出方位 / 距离模糊；宽带接收派生 RFI。本维度部分指标（RFI、模糊可见性）是**场景相关**的，只作可用性标记。

## 4.2 指标详解

### 指标 1 · NESZ（噪声等效散射系数）

| 项 | 内容 |
|---|---|
| 测量方法 | 极低后向散射分布目标（Doldrums 太平洋赤道无风带）交叉极化剖面 |
| 单位 | dB |
| 判据 | TSX −19~−26 dB；GF-3 设计 −20 dB / 在轨实测约 −22 dB |
| 实现 | sct `nesz`、bopen/xarray-sentinel（查表） |

**方法**：只评估交叉极化通道（HV/VH）以降低残余地物回波；整个在轨测试期重复观测，取整体均值最低剖面作为 NESZ 估计；与设计曲线逐入射角比对。

**注意**：NESZ 与 NEBZ 差一个 sinθᵢ。TSX 产品中提供的是 NEBN（噪声等效 beta nought）多项式而非 NESZ 本身，直接当 NESZ 用会引入入射角相关系统偏差。

### 指标 2 · ENL / 辐射分辨率

| 项 | 内容 |
|---|---|
| 测量方法 | 均匀区矩估计 + 对数累积量估计（双估计量） |
| 判据 | GF-3 辐射分辨率 3 dB / 精细模式约 1.5 dB |
| 实现 | **自研（无现成统一库）** |

斑点服从乘性模型：单视强度指数分布，L 视平均后 `I ~ σ⁰·Gamma(L, 1/L)`，`CV = σ/μ = 1/√L`。两种估计量：

- **矩估计**：`ENL_moment = μ² / σ²`（均匀区最优，对纹理极度敏感）
- **对数累积量估计**：由 `Var[log I] = ψ₁(L)` 反解 L（ψ₁ 为三伽马函数，对纹理更稳健）

**关键要求**：ENL 必须报告"在哪些区块上、用哪种估计量、区块如何筛选"，否则数值不可比。**两种估计量出现明显分歧本身就是"所选区块不够均匀"的告警信号**。详见 [08-去斑评价指标包](08-去斑评价指标包.md)。

### 指标 3 · AASR / RASR 模糊比

| 项 | 内容 |
|---|---|
| 测量方法 | 方位谱复制能量占比（AASR）；鬼影识别（RASR） |
| 单位 | dB |
| 判据 | TSX 方位 ≈ −20 dB、距离 ≈ −25 dB |
| 实现 | sct 模糊比分析 |

PRF 必须同时满足两个冲突约束：足够高以避免方位谱混叠（方位模糊），足够低以避免相邻脉冲回波距离交叠（距离模糊）。

**经验**：模糊指标不应压缩成单个标量，且必须与场景对比度联合解释（强目标在暗背景上的鬼影最醒目，极易被目标检测算法误判为真实目标）。

### 指标 4 · RFI 污染比例

| 项 | 内容 |
|---|---|
| 测量方法 | 距离频率—方位时间谱异常 + 行均值 3σ |
| 单位 | 占比（%） |
| 判据 | **场景可用性标记，非合格性判据** |
| 实现 | **自研（无成熟开源实现）** |

**流行度**：Chojka 等 2020 筛查 288 幅 Sentinel-1 SLC，113 幅（39%）受 RFI 污染；中东 47%、东欧 46%，波兰仅 5.7%——**强地域依赖，全局阈值必然失效，必须逐场景检测**。

**检测成熟度**：Artiemjew 等 2021 用 LeNet 类 CNN，中东强 RFI 准确率 92%，弱 RFI 仅 66%~84%。谱域是 RFI 最易识别处（窄带表现为贯穿方位向的亮竖线，宽带表现为局部方位时段的水平亮块）。详见 [09-RFI谱域检测器](09-RFI谱域检测器.md)。

### 指标 5 · 去噪负值率

| 项 | 内容 |
|---|---|
| 测量方法 | 热噪声减除后负像素占比 |
| 判据 | 异常高 = 噪声矢量被高估；异常低 = 噪声未被充分减除 |
| 实现 | 自研；sentinel1denoised 参考 |

**原理**：负像素不是缺陷而是噪声减除的统计必然（噪声估计有方差，逐像素相减必然过减约一半）。但负值比例是有效指标：异常高说明噪声矢量被高估，异常低说明噪声未被充分减除。

### 指标 6 · 丢行 / 坏像元率

| 项 | 内容 |
|---|---|
| 测量方法 | 行/列统计突变检测 + 无效值连通域分析 |
| 判据 | A（严重，面积大）/ D（轻，零星） |
| 实现 | 自研 |

丢行来自下行链路丢包或格式化错误，表现为整行缺失或异常值。行列统计突变 + 连通域分析即可检出。

## 4.3 实现建议

1. 指标 5/6（负值率、丢行）是一维 / 连通域级统计，全量前置筛查第一梯队。
2. ENL（指标 2）与 RFI（指标 4）是本维度两个**明确空白**，需要自研，分别见 08、09 号文档。
3. RFI 与模糊可见性是场景相关量，只输出可用性元数据，不做合格性判决。

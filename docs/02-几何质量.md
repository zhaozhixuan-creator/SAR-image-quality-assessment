# 维度 2 · 几何质量

> 判据来源：已知坐标的地面控制。本维度 5 项指标依赖已知精确坐标的角反射器 / 转发器，或 DEM 正演比对。

## 2.1 维度定位

SAR 是侧视、斜距成像，距离维靠回波延时而非入射角成像，几何畸变与地形强耦合：透视收缩、叠掩、阴影、斜距反序。几何质量质检的目标是量化定位误差与地形校正的正确性。

## 2.2 指标详解

### 指标 1 · 绝对定位精度 ALE

| 项 | 内容 |
|---|---|
| 测量方法 | 角反射器预测（轨道 + 几何模型正演）vs 实测亚像素峰值（过采样插值后取极大） |
| 单位 | m（分距离向 / 方位向） |
| 判据 | S1C：均值 0.55 m / σ0.41 m；GF-3：带控 RMSE 2.56 m、无控 < 50 m |
| 实现 | sct（含 iono/tropo/潮/板块改正） |

**误差预算构成**（不做改正的 ALE 数值毫无可比性）：

| 误差源 | 典型量级 | 改正方式 |
|---|---|---|
| 对流层路径延迟 | 约 2 m | 气象/GNSS 天顶总延迟（EUREF） |
| 距离延时定标（仪器内延迟） | 米级 | 角反射器几何定标（避免转发器，含电子延迟） |
| 双静态效应（TOPS/条带） | 亚米~米级 | 方位时间的距离依赖改正 |
| DEM 高程误差 × tanθ | 随地形与 DEM 精度 | 高精度 DEM |
| 固体潮 | 厘米~分米级 | 固体潮模型（PySolid） |
| 板块运动 | 数 cm/年 | 板块模型 + 参考框架历元归算（ITRF） |
| 轨道位置误差 | 精密星历约 10 cm(3D) | 精密 / 重构轨道 |
| 电离层路径延迟 | C 波段数 cm | TEC 图，按 40.28·TEC/(f²cosΘ) 计算 |
| 参考点坐标精度 | 数 cm | ITRF 框架下差分 GPS 实测 |

**实测基准**：Sentinel-1C（DLR 2025）完成全部改正后斜距残余偏移全 < 2 m、多数 < 1 m，均值 0.55 m、σ0.41 m；TerraSAR-X（Balss 等）完整改正后可达分米级。

**关键经验**：S1C 在约 22° 视角处三个 Stripmap 波位存在均值 1.8 m 的离群偏移，仅出现在 SLC 产品而 L0 旁路处理上消失——**ALE 质检有能力反向定位处理链问题**。

### 指标 2 · 相对定位 / 配准精度

| 项 | 内容 |
|---|---|
| 测量方法 | 互相关偏移；模拟幅度配准残差 |
| 单位 | 像素 / m |
| 实现 | isce2/3、MintPy |

用于多时相、多通道、多子带之间的相对配准质量，是 InSAR 与变化检测的前提。

### 指标 3 · 地形校正（RTC）正确性

| 项 | 内容 |
|---|---|
| 测量方法 | 局部入射角与散射面积一致性 |
| 实现 | bopen/sarsen、isce3 |

RTC（Radiometric Terrain Correction）把斜距后向散射校正到归一化地距坐标系。检查局部入射角与散射面积因子是否正确。

### 指标 4 · 叠掩阴影掩膜完整性

| 项 | 内容 |
|---|---|
| 测量方法 | DEM 正演掩膜 vs 产品掩膜比对 |
| 实现 | sarsen、s1ard、OpenSarToolkit |

叠掩（坡度大于入射角）不可通过几何校正恢复——信息在成像时已混叠。必须检查产品掩膜是否正确标识叠掩 / 阴影区，否则后续统计与分类会被污染。

### 指标 5 · 投影 / 采样间隔一致性

| 项 | 内容 |
|---|---|
| 测量方法 | 元数据 vs 栅格实际几何比对 |
| 实现 | stac-check + 自研 |

检查元数据声明的投影、采样间隔、地理编码参数与栅格实际几何是否一致，防止元数据漂移导致下游定位错误。

## 2.3 实现建议

1. ALE 是最重的一项，依赖角反射器与多步改正，放在第二期用 sct 完成；**sct 内建固体潮、板块运动、电离层、对流层与传感器特定改正**，并附带 rosamond-pt-converter / sarcalnet-survey-converter 可直接接入真实角反射器数据。
2. 指标 4/5（掩膜、投影一致性）可在 L2 级全量运行，作为几何前置筛查。
3. ALE 误差预算表是本维度判据的核心依据，质检报告须逐项列出改正项，否则数值不可比。

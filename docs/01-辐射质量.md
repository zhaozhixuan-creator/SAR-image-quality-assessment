# 维度 1 · 辐射质量

> 判据来源：点目标与分布目标定标。本维度 6 项指标共享同一测量对象（角反射器 / 稳定分布目标）与验证手段（RCS 反演、时序剖面、直方图统计）。

## 1.1 维度定位

辐射质量分两个层面：

- **绝对辐射精度**：后向散射系数的绝对偏差（dB），取决于定标链路（内定标、天线方向图、定标常数）。
- **辐射稳定性**：同一目标在时间、航带、波位上的**一致性**。时序应用（变化检测、土壤湿度、农情监测）对稳定性要求往往比绝对精度更严。

SAR 是主动微波传感器，回波功率受雷达方程约束，因此灵敏度下限、动态范围、饱和都属本维度。

## 1.2 指标详解

### 指标 1 · 绝对辐射定标精度

| 项 | 内容 |
|---|---|
| 测量方法 | 角反射器 RCS 反演 vs 理论 RCS |
| 单位 | dB |
| 判据 | 优 / 良档见 GB/T 24356 扣分模型；工程上 1 dB(3σ) 为常见门槛 |
| 实现 | sct `rcs_error_[dB]`、csiro-auscalval/gecoris |

**实测基准**
- Sentinel-1C（DLR 2025）：综合各误差项（含参考目标精度 0.2 dB）后，绝对辐射精度 0.36 dB(1σ)，即优于 1 dB(3σ)。
- GF-3（《雷达学报》）：绝对辐射精度 1.3~1.4 dB。
- TerraSAR-X 产品规范 v1.6：产品表逐模式给出绝对与相对辐射精度指标。

**注意事项**：辐射精度必须标注置信水平（1σ 还是 3σ）。Sentinel-1 指标"< 1 dB(3σ)"与 DLR 实测"0.36 dB(1σ)"实为一致，直接并列比较会得出 3 倍误差。

### 指标 2 · 辐射稳定性 / 长期漂移

| 项 | 内容 |
|---|---|
| 测量方法 | 雨林等稳定分布目标 γ⁰ 时序 |
| 单位 | dB |
| 判据 | LT-1A：< 1 dB/1000 km、< 0.5 dB/5 天 |
| 实现 | 自研（时序统计）+ 处理器版本元数据审计 |

**要点**：处理器 / 辅助数据版本必须与辐射时序联合审计，版本升级前后的产品在时序分析中不可直接混用。Zink 2013 长期监测显示亚马逊分布目标稳定性 0.2~0.3 dB。一次处理器版本变更会在时序上产生**阶跃**——这类突变只有靠长期趋势监测才能发现。

### 指标 3 · 跨轨天线方向图（EAP）残差

| 项 | 内容 |
|---|---|
| 测量方法 | 均匀场景列均值沿幅宽剖面 |
| 单位 | dB |
| 判据 | Sentinel-1C：俯仰向总增益变化 0.3 dB(1σ)；波位间偏移 ≤ 0.2 dB |
| 实现 | 自研（一维统计） |

**原理**：天线增益随俯仰角变化，跨轨辐射残差表现为距离向的缓慢起伏。子带边缘残差最大，是 EAP 校正不完整的典型信号。

### 指标 4 · 子带 / 拼接辐射一致性

| 项 | 内容 |
|---|---|
| 测量方法 | 子带交界列均值阶跃 |
| 单位 | dB |
| 判据 | 交界处无可见台阶 |
| 实现 | 自研；nansencenter/sentinel1denoised 参考 |

**要点**：多子带拼接（TOPS / ScanSAR）在子带交界处易留辐射台阶。距离向列均值剖面在交界处的**阶跃**即可量化该缺陷，计算成本极低，适合全量前置筛查。

### 指标 5 · 扇贝效应残差

| 项 | 内容 |
|---|---|
| 测量方法 | 方位向行均值周期性起伏 |
| 单位 | dB |
| 判据 | 剖面的峰峰值 / 标准差 |
| 实现 | sct `scalloping` |

**原理**：TOPS / ScanSAR 通过天线波束周期性扫描换取幅宽，代价是方位向增益周期性起伏（scalloping）。方位向行均值剖面会呈现周期性起伏，是检测扇贝残差的标准手段。sct 的关注点是**测量伪影幅度**而非仅仅校正它，更贴合质检需求。

### 指标 6 · 饱和率 / 动态范围

| 项 | 内容 |
|---|---|
| 测量方法 | 直方图上界堆积计数 |
| 单位 | 占比（%） |
| 判据 | 饱和率 → 缺陷类（B 类 / 重） |
| 实现 | 自研 |

**原理**：强散射区（舰船、建筑物、角反射器）超出量化动态范围时，峰值被削平并伴生旁瓣异常（ADC 削波）。直方图上界堆积计数即可得到饱和率。

## 1.3 实现建议

1. 指标 3/4/5/6 都是一维剖面或直方图级统计，**可在全量数据上跑，成本可忽略**，作为第一期的前置筛查。
2. 指标 1/2 依赖角反射器或长时序，放在第二期（sct 引擎）与第三期（版本台账）处理。
3. 所有辐射指标须与处理器版本、辅助数据版本绑定存储，避免版本升级产生系统性误报。

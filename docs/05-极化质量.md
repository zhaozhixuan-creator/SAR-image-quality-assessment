# 维度 5 · 极化质量

> 判据来源：通道间比对与互易性。本维度 5 项指标量化极化通道间的增益 / 相位失配与串扰，这些失真会直接破坏极化分解、分类与目标识别的物理基础。

## 5.1 维度定位

全极化或双极化 SAR 的各通道并非理想独立：通道间存在增益与相位失配，交叉极化通道会混入同极化能量（串扰）。单站 SAR 理论上 VH 与 HV 应统计一致（互易性），显著偏离即指向定标或通道问题。

## 5.2 指标详解

### 指标 1 · 通道幅度不平衡

| 项 | 内容 |
|---|---|
| 测量方法 | VV/HH 沿距离向比值 |
| 单位 | dB |
| 判据 | Sentinel-1C 实测 −0.5~+0.7 dB；LT-1A 约 0.2 dB |
| 实现 | sct 极化分析 + 自研 |

检查同极化通道（VV vs HH）沿距离向的幅度比值，叠加 ±0.5 dB 容差带。

### 指标 2 · 通道相位不平衡

| 项 | 内容 |
|---|---|
| 测量方法 | 同极化相位差统计 |
| 单位 | 度（°） |
| 判据 | LT-1A 约 2° |
| 实现 | sct 极化分析 + 自研 |

### 指标 3 · 交叉极化串扰

| 项 | 内容 |
|---|---|
| 测量方法 | 角反射器或分布目标反演串扰矩阵 |
| 单位 | dB |
| 判据 | LT-1A < −35 dB；ALOS-2（JAXA 2021）实测 −38 dB |
| 实现 | sct；参考 LT-1A 方法 |

串扰越强，同极化相位差分布越发散偏移，直接破坏极化分解的物理基础。

### 指标 4 · 互易性 VH≈HV

| 项 | 内容 |
|---|---|
| 测量方法 | 两通道直方图与逐像素比对 |
| 判据 | 单站 SAR 应统计一致 |
| 实现 | **自研（低成本、高信息量）** |

单站 SAR 的 VH 与 HV 通道理论上应统计一致。逐像素 / 直方图比对即可检出通道问题，计算成本极低，是全量前置筛查的高性价比项。

### 指标 5 · 通道间配准

| 项 | 内容 |
|---|---|
| 测量方法 | 通道间互相关偏移 |
| 单位 | 像素 |
| 实现 | 自研 |

各极化通道在空间上应对齐，配准偏差会破坏 Pauli 分解等需要多通道联合的运算。

## 5.3 实测基准汇总

| 指标 | Sentinel-1C（DLR 2025） | LT-1A（《雷达学报》2024） |
|---|---|---|
| 通道幅度不平衡 | −0.5~+0.7 dB | 约 0.2 dB |
| 通道相位不平衡 | 数度 | 约 2° |
| 串扰 | — | < −35 dB |
| 仪器内部通道稳定性 | 幅度 < 0.1 dB | — |
| 辐射稳定性 | — | < 1 dB/1000 km、< 0.5 dB/5 天 |

## 5.4 实现建议

1. 互易性检验（指标 4）成本最低、信息量高，纳入第一期前置筛查。
2. 串扰反演（指标 3）需要角反射器或已知极化特性的分布目标，放入第二期用 sct 完成。
3. 极化质检须注意：通道不平衡与串扰的数值与测量对象（角反射器 vs 分布目标）强相关，报告须标注测量条件。

# 维度 3 · 分辨率与点目标响应

> 判据来源：点目标定标。本维度 5 项指标共享同一测量对象——孤立强散射体（角反射器、转发器、自然强点）的二维脉冲响应函数（IRF / PTR）。

## 3.1 维度定位

IRF 是 SAR 成像质量最核心的实测对象：一个孤立强散射体的二维响应函数，同时给出**分辨率、旁瓣水平、聚焦质量**三类信息。

SAR 分辨率不由像素间距决定，而由信号带宽（距离向）与合成孔径长度（方位向）决定：

- 距离向：`ρ_r = c / (2 · B · sinθ)`
- 方位向：`ρ_a ≈ L_ant / 2`

两个直接推论：地距分辨率随入射角变化（质检必须分距离位置分别评估）；像素间距通常远小于分辨率（过采样），因此"数像素"永远得不到真实分辨率，必须用点目标脉冲响应实测 −3 dB 主瓣宽度。

## 3.2 指标详解

### 指标 1 · 空间分辨率（−3 dB 宽度）

| 项 | 内容 |
|---|---|
| 测量方法 | 16× 过采样插值后 IRF 主瓣半功率点宽度 |
| 单位 | m |
| 判据 | 矩形谱理论值 0.886 分辨单元；加权后展宽 |
| 实现 | sct `range_resolution_[m]` / `azimuth_resolution_[m]` |

**要点**：必须在过采样后的连续域上测量。直接在原始像素网格取最大值会因峰值落在像素之间而系统性低估峰值、高估主瓣宽度，误差可达 1 dB 以上。

### 指标 2 · PSLR 峰值旁瓣比

| 项 | 内容 |
|---|---|
| 测量方法 | 最高旁瓣峰值 / 主瓣峰值 |
| 单位 | dB |
| 判据 | 加权后工程指标 < −20 dB；GF-3 < −22 dB |
| 实现 | sct `evaluate_pslr` |

**理论值对照**：矩形谱 sinc 未加权理论值 −13.26 dB；Taylor / Hamming 加权可压到 −30 dB 以下，代价是主瓣展宽 20%~30%。分辨率与 PSLR 不能同时优化。

### 指标 3 · ISLR 积分旁瓣比

| 项 | 内容 |
|---|---|
| 测量方法 | 全部旁瓣能量 / 主瓣能量（积分） |
| 单位 | dB |
| 判据 | 工程指标 < −15 dB |
| 实现 | sct `range_islr_[dB]` / `azimuth_islr_[dB]` / `islr_2d_[dB]` |

ISLR 反映强目标对周边弱目标的能量污染总量，对海面油膜、暗目标检测影响最直接。

### 指标 4 · SSLR 次生旁瓣比

| 项 | 内容 |
|---|---|
| 测量方法 | 非邻近旁瓣（成对回波、幽灵）/ 主瓣 |
| 单位 | dB |
| 实现 | sct `range_sslr_[dB]` / `azimuth_sslr_[dB]` / `sslr_2d_[dB]` |

SSLR 反映系统非线性、通道失配、定标残差，sct 单列此项（距离 / 方位 / 二维三个方向）。

### 指标 5 · 散焦 / 展宽因子

| 项 | 内容 |
|---|---|
| 测量方法 | 实测主瓣宽度 / 理论主瓣宽度 |
| 判据 | 展宽因子 ≈ 1 为聚焦正常，显著 > 1 为聚焦退化 |
| 实现 | sct + 自研判据 |

展宽因子直接反映多普勒中心或调频率估计错误、运动补偿不足导致的聚焦退化。

## 3.3 引用陷阱（本维度最密集）

1. **PSLR 加权方式**：ICEYE 均匀加权 −13.3 dB 与 Taylor 加权 −20 dB，同一次成像相差约 7 dB。引用前必须确认加权条件。
2. **ISLR 积分限**：绝大多数规范不写积分限，只有 TSX 规范 TX-GS-DD-3302 附录 A 明确给出，因此只有它的 ISLR 可复算。
3. **分辨率三区分**：标称分辨率 / −3 dB 主瓣宽度 / 像素间距常被混用。ICEYE Spot 模式：标称 1 m、实测 −3 dB 0.78~1.46 m、像素间距 0.5 m。
4. **未加权理论值陷阱**：文献中 PSLR −13.25 dB / ISLR −9.97 dB 是未加权 sinc 理论值，不可与加权后的工程指标直接对比。

## 3.4 实现建议

1. IRF 类指标只在 SLC 级有效——在地距产品上测 IRF 已失真（重采样破坏脉冲响应）。
2. 用 sct 的默认参数作为对齐基准：`oversampling_factor=16`、`peak_finding_roi_size=[33,33]`、`analysis_roi_size=[128,128]`。
3. 若发现某产品分辨率异常优于标称值，应同时检查 PSLR 是否劣化——往往是处理器加权配置被改动的信号。

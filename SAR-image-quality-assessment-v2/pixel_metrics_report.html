摘要

对 DDIM 扩散模型生成的 80 张 SAR 图像进行 7 项全参考指标的量化质检。核心结果为 PSNR = 22.53 dB、MSE = 0.0063、 NCC = 0.1680、UQI = 0.0097、 MS-SSIM = 0.1208、FSIM = 0.5766。 MSTAR 公开集验证表明 7 项指标实现正确、且均能区分自洽（real-real2）与退化（real-fake）样本。 对生成集的评估显示：结构感知类指标（FSIM=0.577、MS-SSIM=0.121）表明生成图保留了目标的粗轮廓 与相位结构，但精细纹理与散射细节明显缺失；逐像素相关类指标（NCC=0.168、UQI=0.010）大幅 偏离理想值，主要由 SAR 乘性散斑的逐点随机相位不相关、以及 UQI 在暗背景 SAR 图上的分母退化 （μ≈0）共同导致。整体结论：生成图结构可辨、逐像素保真弱、类间差异明显（BRDM2 最差、D7 最好）， 与六项核心指标报告的"对比度/动态范围缺陷"结论互为印证。

1 引言

本报告在项目既有六项核心指标（FID/SSIM/AFS/ΔENL/BVE/CMAE）之外，补充 arXiv 2411.05027 （生成式 AI 与 SAR 综述）所列举的经典全参考（Full-Reference）图像质量指标，从逐像素保真与 结构感知保真两个互补维度，回答"生成图与真实 MSTAR 在像素级与结构级分别差多少"。 其中 MSE/RMSE/PSNR 衡量逐点灰度一致性，NCC/UQI 衡量灰度涨落的相关性与统计一致性， MS-SSIM/FSIM 衡量多尺度结构与感知特征（相位一致性、梯度幅度）的相似度。三者层次递进： 像素 → 统计 → 结构。

2 方法与数据

2.1 域对齐

生成图为模型原始输出域 [-1,1]；真实参考为 mstar_raw 展开的幅度切片（原始最大值约 15.97）。为统一到 [0,1] 灰度域并保证 data_range=1 口径一致，逐对做 pair-01 归一化：含负值输入先 (x+1)/2 映射到 [0,1]，再按该对两图的联合最大值缩放。该 口径与 ssim() 的归一化思路一致，使绝对亮度尺度不干扰比较。

2.2 配对方式

生成图 labels.npy 仅含类别标签、无方位角，故采用同类交叉全配对取平均：每张 生成图与其同类别全部真实参考图（每类 72 张）逐张计算指标后取平均，再对 80 张生成图取平均。 该口径下每张生成图的指标值反映"与真实同类目标整体分布的接近程度"，而非与某一特定角度的对齐。

2.3 指标定义

MSE = (1/N) Σi ⟨(ri − fi)²⟩，  RMSE = √MSE
PSNR = 10·log10(DR² / MSE)，  DR = 1（[0,1] 域），单位 dB
NCC = (1/N) Σi [ Σp(rip−μr)(fip−μf) / (√Σ(r−μr)² · √Σ(f−μf)²) ] ∈ [−1,1]
UQI = (1/N) Σi [ 4·σrf·μr·μf / ((σr²+σf²)(μr²+μf²)) ]，  相关×亮度×对比度
MS-SSIM = (1/N) Σi [ lMαM(r,f) · Πj=1..M cjβj(r,f) sjγj(r,f) ]
FSIM = (1/N) Σi [ Σp SL(p)·PCm(p) / Σp PCm(p) ]，  SL=SPC·SG

其中 ⟨·⟩ 表示逐像素平均，ri/fi 为第 i 对参考/生成图。 PC = 相位一致性（phase congruency），G = 梯度幅度（gradient magnitude），PCm 取两图较大者。 UQI 为 Wang & Bovik (2002) 通用质量指数（SSIM 的前身，无稳定性常数）；MS-SSIM 为 Wang et al. (2003) 多尺度扩展；FSIM 为 Zhang et al. (2011) 特征相似度。

4 缺陷诊断

缺陷 1：精细纹理与散射细节缺失（结构保真不足）严重

证据：结构感知指标 MS-SSIM 仅 0.121、FSIM 仅 0.577（理想值 1）。FSIM 保留了约 58% 的相位/梯度结构（目标轮廓与主体形状 基本可辨），但 MS-SSIM 的多尺度分析显示，从粗到细的结构相似度逐级衰减——即粗尺度结构尚在、 细尺度纹理与散斑结构大量丢失。这与扩散模型以 L2 损失训练、倾向于生成"平均化"光滑图像的 特性一致。

缺陷 2：逐像素灰度相关性几乎消失严重

证据：NCC 由自洽的 0.9997 跌至生成的 0.168。逐点灰度涨落与 真实图几乎不相关，根因是 SAR 乘性散斑的逐点随机相位——不同采样下的散斑实现互不相关。由于采用 同类交叉全配对（生成图与真实参考的散斑相位无对应关系），逐像素相关天然很低。此指标反映的是 "散斑纹理能否逐点复现"，对 SAR 生成任务通常不可达，应结合结构指标解读。

缺陷 3：类间质量不均衡（BRDM2 最差、D7 最好）中等

证据：结构指标一致显示 BRDM2 最差（FSIM=0.418、 MS-SSIM=0.039），D7 最好（FSIM=0.742、 MS-SSIM=0.214）。逐像素保真同样如此（PSNR：BRDM2 最差 19.6 dB、D7 最好 25.5 dB）。 不同类别目标的结构复杂度与训练样本覆盖度差异，导致生成质量显著分层，需按类针对性改进。

说明：UQI 接近零属指标局限，非真实缺陷局限

证据：UQI 总体仅 0.0097，明显低于其它指标。根因是 UQI 分母含 μr²+μf² 项——SAR 图暗背景占主导（目标占比小），平均灰度 μ 接近 0，使分母 趋于 0、数值不稳定且系统性偏低。验证阶段自洽值 0.9997 证明实现正确；此处低值不应解读为 生成器缺陷，而应理解为 UQI 对暗背景 SAR 图适用性差。MS-SSIM 与 FSIM 内置稳定性常数 （C₁/C₂、T）故不受此影响，是本任务更可靠的选择。

缺陷 4：整体亮度/动态范围与真实 SAR 有系统偏差中等

证据：PSNR 总体 22.5 dB、MSE 0.0063（归一化域）。这一量级 表明生成图的整体灰度分布与真实参考存在系统性的亮度/动态范围偏差，与六项核心指标报告诊断的 "目标对比度不足 + 动态范围压缩"结论互为印证——扩散模型抑制了高强度散射中心、拉平了动态范围。

5 结论

7 项全参考指标的验证与评估表明，生成图在结构感知维度表现最好（FSIM=0.577， 保留相位结构与目标轮廓），但逐像素保真维度严重偏弱（NCC=0.168、 UQI=0.0097）。这一"结构可辨、像素不相关"的格局是 SAR 乘性散斑 + 无方位角对齐的 必然结果：真实 SAR 的散斑逐点相位随机，任何生成器都难以在逐像素意义上复现其灰度涨落。因此， 对本任务而言FSIM 与 MS-SSIM 是最可信、最有判别力的两项指标，而 NCC/UQI（尤其 UQI）因 暗背景与乘性噪声，只宜作为相对参考、不宜作为绝对质量门槛。建议以 FSIM 为主、MS-SSIM 为辅、 PSNR 作整体亮度一致性旁证，来追踪生成器迭代过程中的结构保真进展。

附录 A　指标公式与实现来源

MSE/RMSE/PSNR 为经典逐像素保真指标；NCC（归一化互相关）与 UQI（Wang & Bovik, IEEE TIP 2002）为统计相关类；MS-SSIM（Wang et al., Asilomar 2003）与 FSIM（Zhang et al., IEEE TIP 2011）为结构/感知类。实现分别基于 sewar（UQI/PSNR 对照）、 pytorch-msssim（MS-SSIM）、piq（FSIM，chromatic=False 适配灰度 SAR）。 上述七项在 arXiv 2411.05027 中作为生成式 SAR 图像质量评估的可选指标被列举。

附录 B　实现口径与局限

  1. 所有指标均逐对归一化到 [0,1] 后计算，data_range=1；含负值输入按 (x+1)/2 映射。
  2. 指标采用逐对计算后取平均的口径：MSE 为逐对 MSE 的均值，RMSE 为逐对 RMSE 的均值， PSNR 为逐对 PSNR 的均值。由 Jensen 不等式，均值口径下 RMSE ≤ √(总体 MSE)、PSNR(均值) ≥ PSNR(总体 MSE)，故表中 RMSE 与 √MSE、PSNR 与 10·log10(1/MSE) 不完全互为逆运算。
  3. 生成图无方位角标签，采用同类交叉全配对而非角度匹配；SAR 对方位角敏感，散斑逐点 随机相位导致 NCC/UQI 系统性偏低，属口径与数据特性所致，非实现错误。
  4. UQI 分母含 μ² 项，暗背景占主导（目标占比小）时 μ≈0，UQI 数值不稳定、会系统性偏低——属指标 自身在 SAR 上的适用范围局限，已在缺陷诊断中单独标注，不作为生成器真实质量缺陷解读。
  5. 本报告为独立的全参考指标报告，与六项核心指标报告（run1_quality_report.html）互补、不合并。

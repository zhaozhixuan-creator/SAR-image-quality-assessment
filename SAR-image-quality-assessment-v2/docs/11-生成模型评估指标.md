# 生成模型评估指标（论文 §3.1.4）

本文对应《Remote Sensing》论文 §3.1.4 的六项评估指标，用于比较**真实 SAR 图像集**与
**生成图像集**。与 `sar_iqa`（单图质检）不同，这里评估的是生成模型本身。

实现位于 `gan_metrics/`，与 `sar_iqa/` 相互独立。

## 六项指标速览

| 组别 | 指标 | 趋势 | 公式要点 | 是否需要预训练模型 |
|---|---|---|---|---|
| 图像保真 | FID | ↓ | 特征高斯分布的 Fréchet 距离（式 38） | Inception-v3（开源现成，冻结） |
| 图像保真 | SSIM | ↑ | 亮度·对比度·结构三分量（式 39） | 否 |
| 目标区物理一致性 | AFS | ↑ | ASC 特征余弦相似度（式 40） | E_asc（自研，冻结） |
| 背景统计一致性 | ΔENL | ↓ | 背景区 |ENL 差| 均值（式 41） | 否 |
| 背景统计一致性 | BVE | ↓ | 背景区 |σ² 差| 均值（式 42） | 否 |
| 角度条件一致性 | CMAE | ↓ | 循环平均绝对误差（式 44） | R(·)（自研，冻结） |

## 各指标公式与实现说明

### FID（式 38）
```
FID = ‖μr − μg‖² + Tr(Σr + Σg − 2(Σr Σg)^{1/2})
```
用 Inception-v3 提取特征（2048 维），假设两组特征服从高斯分布，计算 Fréchet 距离。
- 实现：`gan_metrics/inception.py` + `metrics.fid`。
- 数值稳定：本实现先 PCA 降到 `min(64, N−1)` 维再算协方差，避免小样本下 2048×2048
  协方差秩亏导致 `sqrtm` 不稳定（论文样本数 180 亦远小于 2048，此为文档化偏差）。
- 灰度→RGB 复制三通道，用跨集一致的全局最大值归一化到 [0,1]，再 resize 到 299。

### SSIM（式 39）
全参考逐像素指标，`skimage.metrics.structural_similarity`，逐对计算后取平均。
注意 SAR 相干斑导致像素级不对齐，SSIM 天然偏低（论文值 0.2~0.36），这是指标局限。

### AFS（式 40）
```
AFS = (1/N) Σ cos(E_asc(x_t), E_asc(x̂_t))
```
`E_asc` 为「预训练且冻结的 ASC 提取器」，论文未公开其训练协议。本实现以浅层卷积编码器
（5 卷积块 → GAP → 128 维）+ 重构自监督在真实目标切片上预训练，作为 ASC 感知特征的
简化替身（`models.ASCExtractor` / `ASCAutoencoder`）。

### ΔENL（式 41）与 BVE（式 42）
```
ENL = μ²/(σ² + ε),  ε = 1e-6
ΔENL = (1/N) Σ |ENL(x_b) − ENL(x̂_b)|
BVE  = (1/N) Σ |σ²(x_b) − σ²(x̂_b)|
```
背景区 `Mb = 1 − Mt`，`Mt` 为中心 0.4H×0.4W 方形（论文固定掩码）。纯统计量，无需训练。

### CMAE（式 44）
```
CMAE = (1/N) Σ min(|φ̂ − φ|, 360 − |φ̂ − φ|)
```
`φ̂` 由方位角估计器 `R(·)` 反推。`R` 为轻量 CNN（4 卷积块 16/32/64/128 → GAP → 2 FC），
输出 `(sin φ, cos φ)`，训练损失为正余弦 MSE（式 43），仅在真实图上训练。

## 运行

```bash
cd SAR-image-quality-assessment-v2
python examples/download_mstar.py           # 下载真实 MSTAR .npz → mstar_raw/
python examples/mstar_to_chips.py           # 转换 → mstar_real/（10 类 × 72 角）
python examples/eval_gan_metrics.py         # 训练 R/E_asc + 计算六项指标
# 跳过较慢的 FID： python examples/eval_gan_metrics.py --no-fid
```

输出两列对照：`real-real2`（自洽性，接近理想值即实现正确）与 `real-fake`（退化偏离）。
`mstar_raw/`、`mstar_real/` 为数据目录，已在 `.gitignore` 中忽略。

## 算力说明

评估阶段算力可忽略：FID/SSIM/ΔENL/BVE 无需训练（FID 仅 Inception 前向）；AFS/CMAE
各依赖一个小 CNN（约 10 万参数量级），预训练与前向均在秒级。真正耗算力的是生成模型的
训练（论文为 StyleGAN2 骨干、2×RTX 2080Ti、1500 kimg），而非这些评估指标。
